### The analytical questions

```text
Descriptive   → What happened?
Diagnostic    → Why did it happen?
SPC           → Is the process stable and in control?
Predictive    → What is likely to happen?
Prescriptive  → What should we do?
Cognitive     → How can we interact with and interpret the analytics?
```

The long-term goal is to combine **manufacturing domain knowledge, analytics, statistical methods, modern data platforms, optimization and AI** into practical industrial applications.
